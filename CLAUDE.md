# Riff Project Configuration

## gstack Skills Suite

This repository is equipped with **gstack** by Garry Tan. Use the following slash command skills for product planning, architecture, security, design, code reviews, QA, and release management:

### 1. Thinking & Planning
- `/office-hours` — Product interrogation with 6 forcing questions
- `/plan-ceo-review` — Founder-level strategic challenge & scope review
- `/plan-eng-review` — Architecture, data flow diagrams, edge cases, and test plan
- `/plan-design-review` — Design quality review, typography, anti-slop audit
- `/plan-devex-review` — Developer experience & API onboarding review
- `/autoplan` — Fully automated CEO → Design → Eng review pipeline
- `/spec` — Turn vague ideas into precise, executable specs

### 2. Design & Frontend
- `/design-consultation` — Design systems & high-fidelity mockups
- `/design-shotgun` — Generate multiple UI variants & browser comparison
- `/design-html` — Convert mockups to production-ready components
- `/diagram` — Generate Mermaid / Excalidraw vector diagrams

### 3. Review, Debugging & Security
- `/review` — Staff engineer code review for edge cases, performance, & race conditions
- `/investigate` — Systematic root-cause debugging methodology
- `/cso` — Chief Security Officer OWASP Top 10 + STRIDE threat audit
- `/codex` — Second opinion review via OpenAI Codex CLI

### 4. QA, Browser & Testing
- `/browse` — Real Chromium headless/headed browser for web navigation & inspection
- `/qa` — Automated browser testing, bug discovery, and regression fixes
- `/qa-only` — Pure QA testing and reporting without code changes
- `/benchmark` — Performance benchmarks, Core Web Vitals, and resource tracking
- `/canary` — Post-deploy monitoring loop for console errors and latency

### 5. Shipping & Documentation
- `/ship` — Verify tests, sync main, audit coverage, push, and open PR
- `/land-and-deploy` — Merge PR, monitor CI/CD, and verify production health
- `/document-release` — Update project documentation to match shipped features
- `/document-generate` — Author reference, how-to, and architecture docs via Diataxis
- `/make-pdf` — Export markdown and vector diagrams to PDF/DOCX
- `/retro` — Weekly engineering retrospective and velocity analysis

### 6. Safety & Maintenance
- `/guard` — Maximum safety guardrails (`/careful` + `/freeze`)
- `/freeze` / `/unfreeze` — Directory edit lock to prevent accidental changes
- `/careful` — Warning prompts before destructive operations
- `/gstack-upgrade` — Keep gstack skills and binaries up to date

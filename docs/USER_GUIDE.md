# 📖 Riff User & PWA Installation Guide

Welcome to **Riff**, your universal progressive web music streaming and offline listening app!

---

## 1. How to Install Riff as a Native PWA

### On Android (Chrome / Brave / Edge)
1. Open Riff in your browser.
2. Tap the **three dots menu (⋮)** in the top right.
3. Select **"Install app"** or **"Add to Home screen"**.
4. Riff is now installed with full offline capability, lockscreen notification player, and standalone window mode!

### On iOS (Safari)
1. Open Riff in Safari.
2. Tap the **Share button (square with arrow pointing up)** at the bottom.
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **Add** in the top right corner.

### On Desktop (Chrome / Edge / Windows / Mac)
1. In the browser address bar, click the **Install icon (⊕)** on the right side.
2. Click **Install**.
3. Riff opens in its own dedicated window with hardware media key support.

---

## 2. Using Riff Features

### 🎵 Streaming Music Online
* Browse top trending hits and daily mixes on the **Home** tab.
* Search for any artist, song, album, or live FM radio station on the **Explore** tab.
* Tap any song card to begin playing instantly.

### 📥 Playing Local Audio Files
* Go to **Your Library** $\rightarrow$ **Local MP3s**.
* Drag and drop any `.mp3`, `.flac`, `.wav`, `.aac`, or `.m4a` files directly onto the dropzone.
* Songs are ingested directly into your browser's **Origin Private File System (OPFS)** for instant offline playback.

### 🎤 Synchronized Karaoke Lyrics
* Click the **Microphone (🎤)** icon in the player bar or expand to Fullscreen.
* Real-time synchronized lyrics will glow and auto-scroll in sync with the song.
* **Tap-to-Seek:** Tap on any lyric line to jump the song directly to that timestamp!

### 📶 Adaptive Data Saver Mode
* Open **Settings (⚙️)**.
* Choose between **Auto**, **High (320k)**, **Standard (160k)**, or **Data Saver (96k)**.
* On Cellular / Mobile data, Riff automatically optimizes bandwidth to consume minimal SIM data.
